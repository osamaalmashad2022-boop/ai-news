### بنية تحتية متقدمة لوكلاء الذكاء الاصطناعي
أعلنت شركة OpenAI عن إطلاق واجهة التطبيقات البرمجية Agents API في مرحلة المعاينة العامة، متيحة للمطورين الوصول إلى البنية التحتية التي تُشغّل نموذج Codex وخدمات ChatGPT.

### أبرز مميزات الواجهة الجديدة:
- **إدارة السياق تلقائياً:** التعامل مع السياقات الطويلة واسترجاع البيانات بمرونة.
- **التنفيذ الموازي للأدوات:** تشغيل أدوات متعددة وتكليف وكلاء فرعيين بمهام مخصصة.
- **خيارات متعددة لبيئات التشغيل:** إمكانية التشغيل ضمن بيئات معزولة تستضيفها OpenAI أو شركاء مثل Cloudflare وVercel وOracle.
- **احتساب التكلفة:** يتم التسعير بناءً على عدد الرموز (Tokens) فقط دون رسوم إضافية.
