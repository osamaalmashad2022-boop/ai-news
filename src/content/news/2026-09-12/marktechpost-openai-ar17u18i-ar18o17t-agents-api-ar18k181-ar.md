### مزايا واجهة Agents API
* **البنية التحتية:** تعتمد الواجهة على بيئة Codex المدارة لضمان استمرارية تشغيل الوكلاء لفترات طويلة وبكفاءة عالية.
* **المكونات الأساسية:** تنظم الواجهة العمل عبر 4 عناصر رئيسية: الوكيل (Agent)، البيئة (Environment)، الجلسة (Session)، والأحداث (Events).
