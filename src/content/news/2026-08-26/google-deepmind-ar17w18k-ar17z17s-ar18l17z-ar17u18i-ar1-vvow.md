### تقنية جديدة للتفريغ الصوتي الفوري

أطلقت **Google DeepMind** نموذج **Gemini 3.5 Transcribe** ليوفر تجربة تحويل الصوت إلى نص مكتوب مصقول ومنسق بدقة عالية بدلاً من النماذج التقليدية التي تعاني مع الضوضاء والمصطلحات المعقدة.

* **واجهات برمجية متعددة:** يتوفر النموذج عبر Live API للتفريغ المباشر بزمن استجابة يقل عن الثانية، إلى جانب API المعالجة غير المباشرة.
* **إتاحة شاملة:** يمكن للمطورين استخدام النموذج عبر Gemini API في Google AI Studio ومنصة Gemini Enterprise Agent Platform.
* **تطبيقات واسعة:** يدعم بناء وكلاء صوتيين، أنظمة التسمية التوضيحية الفورية، وتحليل المكالمات.
